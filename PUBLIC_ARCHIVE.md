# Public archive scope

This repository is the public source, protocol, test, and lightweight evidence
archive for the [Hyperspectral Tree Species Identification Challenge
2026](https://www.kaggle.com/competitions/tree-species-hsi-2026). It combines
the committed Phase 1 baseline with an explicitly inventoried overlay of the
later Phase 2 working-tree research.

It deliberately excludes raw competition inputs, downloaded payloads,
absolute-path data links, data-derived model artifacts, generated submission
CSV/ZIP files, partial downloads, environments, and caches. The competition's
data-specific terms restrict redistribution even though the Kaggle metadata
also names CC BY-NC-SA 4.0; the stricter competition boundary controls this
archive.

Portfolio index: [kaggle-research-portfolio](https://github.com/openkaggle/kaggle-research-portfolio).
Related archives include [ARC-AGI-2](https://github.com/openkaggle/arc2-paper-research),
[TartanIMU](https://github.com/openkaggle/tartan-imu-research), and
[Traffic Flow Bench](https://github.com/openkaggle/traffic-forecasting-research).

The manifest and provenance files bind the published source snapshot without
claiming that omitted bytes are backed up by GitHub.
