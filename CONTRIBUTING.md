# Contributing

OpenKaggle welcomes reproducible code, research notes, careful corrections, and
small experiments. Explain the evidence and checks behind each contribution.

Do not commit private credentials or raw organizer data that the competition
terms do not allow us to redistribute. Prefer official links, version IDs,
hashes, schemas, and derived evidence.

## Cite this repository

Use GitHub's **Cite this repository** action, or copy the canonical entry from
[`CITATION.bib`](CITATION.bib) / [`CITATION.cff`](CITATION.cff). Keep the
snapshot version and URL when citing this release.
